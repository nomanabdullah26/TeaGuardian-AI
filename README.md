# 🍃 TeaGuardian-AI

**An AI-powered tea leaf analysis application built with Streamlit and deep learning.**

TeaGuardian-AI is a machine learning project designed to analyze tea leaf images using trained deep learning models. The application provides separate models for tea leaf age classification and disease classification through a user-friendly web interface.

## ✨ Features

* **Tea Leaf Age Classification:** Uses a trained deep learning model to classify tea leaf age.
* **Tea Leaf Disease Classification:** Uses a separate trained model to classify tea leaf diseases.
* **Interactive Web Interface:** Built with Streamlit for an accessible and easy-to-use experience.
* **Image-Based Prediction:** Allows users to analyze tea leaf images through the application.
* **Custom Styling:** Includes a custom CSS stylesheet to enhance the user interface.
* **Reusable Utilities:** Uses separate utility functions to organize application logic and model-related operations.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/afrin2326/TeaGuardian-AI.git
```

### 2. Navigate to the project directory

```bash
cd TeaGuardian-AI
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

Activate the environment.

**Windows (Command Prompt):**

```bash
venv\Scripts\activate
```

**Windows (Git Bash):**

```bash
source venv/Scripts/activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Run the application

From the project root directory, execute:

```bash
streamlit run app/app.py
```

Streamlit will provide a local URL in the terminal, usually:

```text
http://localhost:8501
```

Open the URL in your browser to use TeaGuardian-AI.

## 🧠 Model Information

TeaGuardian-AI uses two separately trained Keras models:

| Model                  | File               | Purpose                         |
| ---------------------- | ------------------ | ------------------------------- |
| Age classification     | `age_model.h5`     | Tea leaf age classification     |
| Disease classification | `disease_model.h5` | Tea leaf disease classification |

The associated class mapping and class-name files are stored in the `models/` directory. These files help the application map model output classes to their corresponding labels.

### Large Model Files

The trained `.h5` model files are managed using **Git Large File Storage (Git LFS)** because deep learning model files can exceed GitHub's standard file-size limit.

If Git LFS is installed, download the repository with:

```bash
git lfs install
git clone https://github.com/afrin2326/TeaGuardian-AI.git
```

If the model files appear as small text pointer files after cloning, fetch the actual files using:

```bash
git lfs pull
```
